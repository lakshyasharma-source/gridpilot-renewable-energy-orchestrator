# Prepared demo walkthrough

`GridPilot_Demo.mp4` is a 2-minute-30-second silent, captioned walkthrough assembled from actual browser captures of the expanded application. It is an edited sequence of screenshots, not a continuous screen recording. It contains no invented interface values or generated dashboard images.

The walkthrough shows the autonomous stages, objective weights, editable inputs, a resulting reliability decision, consumer schedules, wind surge, cloud/price shocks, tool rejection and recovery, maintenance delay, constrained grid service, a complete day, JSON export and architecture. It explicitly labels the simplified model and simulated actions.

The day section resets the simulation and then appends 96 intervals to its initial dispatch, giving 97 recorded cycles. The prototype reported 99.9% demand served and zero pending shifted energy in this browser run. This is separate from the fresh 96-cycle scenario evaluations in `VALIDATION.md`.

Video verification: 1280 x 1024 pixels, 12 frames/second, 1,800 frames, 150 seconds, H.264 MP4. Every frame decoded successfully. A final voice-led screen recording using `DEMO_SCRIPT.md` is available as an optional improvement. Check the portal's current video format requirements before upload.
